# Franky
<p align="center">
  <img src="assets/franky_logo.png" alt="Franky Logo" width="150"/>
</p>

<p align="center">
  <b>A lightweight Python GUI tool to preview CSV, Parquet, and JSON files</b>
</p>

---

## 🚀 Features

- 📂 Load and preview **CSV, Parquet, JSON** files
- 🖥️ Simple and clean GUI built with PySide6
- ⚡ Fast preview using Pandas
- 🎯 Designed for quick data inspection

---

## 🛠️ Tech Stack

- Python 3.x  
- PySide6  
- Pandas  
- PyArrow (for Parquet support)

---
